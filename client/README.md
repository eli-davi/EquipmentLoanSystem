# Equipment Loan – React Client

לקוח להדגמת שרת ה-API (התחברות/הרשמה עם JWT, רשימה עם pagination מול השרת, השאלה/החזרה, וטיפול ב-409).

```bash
npm install
npm start          # http://localhost:3000
```

כתובת השרת: ברירת המחדל `http://localhost:5000`. לשינוי - ליצור `.env` לפי `.env.example`.

**הודעות השאלה:** לחיצה ראשונה על "השאל עכשיו" → "הפריט הושאל בהצלחה". לחיצה על פריט שכבר מושאל (השרת מחזיר 409) → "זה כבר מושאל".

**מצב הדגמה:** אם השרת לא זמין, רשימת הציוד נטענת מתוך `LOCAL_EQUIPMENT` שב-`src/App.js`
והמערכת ממשיכה לעבוד (השאלה, החזרה והודעות) בלי שרת ובלי בסיס נתונים.
